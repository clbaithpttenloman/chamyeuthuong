♥ Mockup thiệp v3 — chỉ để duyệt thiết kế (không phải code thật)

1. Sáu layout thông dụng

Mỗi layout chỉ định khung hình (3:4 dọc hoặc 4:3 ngang) và vùng viết. Ảnh nền hiện rõ 100%. Chữ viết thẳng lên thiệp. Ảnh nền mẫu dưới đây vẽ hoa tránh vùng viết. Ảnh thật do admin tải lên. Bật "Hiện vùng viết" để xem khung admin dùng khi canh ảnh.

2. Học sinh viết thiệp

Mẫu thiệp (ảnh nền + layout) do admin tạo. Học sinh chọn mẫu, rồi chọn font và màu mực khi viết. Bản xem trước cập nhật ngay. Thiệp nhỏ bên cạnh là cách thiệp hiện trong danh sách, cùng tỉ lệ và cùng bố cục với thiệp lớn. Lời chúc dài thì chữ tự thu nhỏ cho vừa vùng viết.
